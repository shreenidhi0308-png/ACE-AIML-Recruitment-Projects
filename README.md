# ACE AIML Club Recruitment Projects

This repository contains the Machine Learning projects completed as part of the ACE AIML Club recruitment process.

## 1. House Price Prediction (Regression)
A regression project focused on predicting house prices using housing features.

- Data preprocessing
- Categorical encoding
- Log transformation
- XGBoost, LightGBM, and CatBoost
- Weighted ensemble learning
- Evaluation using MSLE

## 2. Customer Classification
A classification project focused on predicting customer outcomes from customer-related data.

- Data cleaning and preprocessing
- Feature engineering
- Categorical encoding
- Multiple classification models
- Ensemble learning
- F1-score evaluation

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, XGBoost, LightGBM, CatBoost, Kaggle
